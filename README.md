# Sovern Partners

A responsive, people-focused website for executive search and leadership advisory, built with Next.js and React.

## Run locally

```sh
npm ci
npm run dev
```

## Check the site

```sh
npm run lint
npm run build
```

See [CONTENT_GUIDE.md](CONTENT_GUIDE.md) for editable content locations, sample biographies, contact-form behaviour, image sources and private preview instructions.

All existing public page URLs are retained. The redesigned contact, candidate and concern forms prepare email drafts; they do not store or submit personal information to a backend.
